            Дополнение hosts от разработчика GUI
            —
          

          

            Добавляет в системный hosts альтернативные IP для ряда сервисов — может помочь, если
            основные адреса заблокированы у вашего провайдера. Список сервисов и адресов не
            фиксирован: он загружается из GitHub-репозитория (ниже) и может обновляться, поэтому
            здесь не указывается конкретный перечень. Требуются права администратора. Список
            кэшируется на случай отсутствия интернета.
          

          

          

            
            
            
          

        


        

          
Active fake-файлы

          

            
            
            
          

          

            
            
            
          


          


          
Автоподбор нет в оригинале

          

            Фиксирует текущую выбранную стратегию, по очереди подменяет ACTIVE fake-файл каждым .bin-кандидатом
            и прогоняет каждый вариант через тот же полноценный тестер, что используется для подбора стратегий:
            targets.txt, HTTP/1.1, TLS 1.2, TLS 1.3, ping, параллельные проверки и оригинальная аналитика.
            Active fake автоматически не меняется — лучший вариант можно выбрать в результатах и применить вручную.
          

          

            
            
          

          

          

          

          

        


        

          
          
          
          

            Перебирает все стратегии тем же полноценным тестером, что и внешний PowerShell:
            targets.txt, HTTP/1.1, TLS 1.2, TLS 1.3, ping, параллельные проверки,
            восстановление исходного состояния и итоговая аналитика. Внутри GUI окно PowerShell
            скрыто, а его вывод и подробные результаты показываются прямо здесь.
          

          

          

        

      


      

        

          

            Telegram-прокси (tg-ws-proxy)
            —

            отдельный процесс рядом с winws — их можно использовать вместе или по отдельности.

            DNS (Quad9)
            —
          

          

            Переключает DNS-сервер на активных сетевых адаптерах на адреса, указанные ниже
            (по умолчанию Quad9: основной 9.9.9.9 и альтернативный 149.112.112.112). При
            отключении DNS возвращается на автоматический (DHCP). Требуются права администратора.
          

          

            
            
          

          

            DoH
            —
            
          

        


        

          
Изменить DNS

          

            Здесь можно указать другой DNS вместо 9.9.9.9 и его альтернативного — именно эти
            адреса будут использоваться кнопками «Включить DNS» / «Отключить DNS» выше.
            Альтернативный адрес необязателен. DoH (DNS поверх HTTPS) для защиты DNS-запросов
            от перехвата и подмены на уровне провайдера включается автоматически для любого
            адреса: для известных публичных DNS (Quad9, Google, Cloudflare и др.) используется
            готовый шаблон, а для остальных приложение само пробует определить поддержку DoH
            по этому же адресу. Если сервер не поддерживает DoH, DNS всё равно продолжит
            работать, просто без шифрования.
          

          

            
            
            
            
          

          

            
            
            
            
          

          

            
          

        

      


    


    

      Работает только на Windows и требует прав администратора (для драйвера WinDivert).
